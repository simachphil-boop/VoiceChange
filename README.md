# VoiceChange 🎙

Android-приложение из двух частей:

- **🎵 Напой**: напеваешь мелодию, а приложение распознаёт ноты, определяет тональность и темп, подбирает аккорды и играет трек в одном из 8 стилей (пианино, лоу-фай, рок, оркестр, джаз, 8-бит, электро, шкатулка). Умеет продолжать мелодию, исправлять фальшь, менять тон и темп, сохранять WAV и MIDI.
- **🎭 Голоса**: 37 эффектов голоса (гелий, монстр, демон, призрак, шёпот, киборг, автотюн, поющее трио, хор, рация, космонавт, диктор на вокзале, пещера и др.) и конструктор своего голоса.

APK собирается автоматически через GitHub Actions. Готовый файл лежит в разделе **Releases**.
